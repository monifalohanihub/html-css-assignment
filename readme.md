# Student Portal Website

## About the Project

This project is a simple and responsive Student Portal website created using HTML and CSS. It is designed to provide students with an easy-to-use interface for accessing basic information about courses and the portal.

## Features

* Home section
* Courses section
* About section
* Contact section
* Notice section
* Responsive navigation bar
* Course cards
* Simple and clean user interface

## Technologies Used

* HTML5
* CSS3

## Project Structure

HTML/
│
├── index.html
├── style.css
└── README.md

## Courses

The website currently includes information about:

* Web Development
* C# Programming

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open 'index.html' in a web browser.

## Purpose

This project was created as part of a university web development assignment to practice HTML structure, CSS styling, navigation, responsive layouts, and basic webpage design.
